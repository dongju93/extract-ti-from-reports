LockBit 3.0 Ransomware: Technical Analysis and Defensive Guidance
Published: 2024-01-22
Source: Cisco Talos Intelligence Group
TLP: WHITE

==============================================================================
EXECUTIVE SUMMARY
==============================================================================

This report provides a deep technical analysis of LockBit 3.0 (also referred to
as LockBit Black), the latest iteration of the LockBit ransomware-as-a-service
(RaaS) operation. In late 2023 and early 2024, Talos observed a significant uptick
in LockBit 3.0 intrusions targeting critical infrastructure, manufacturing, and
legal services organizations in North America, Europe, and Australia.

LockBit 3.0 introduced a bug bounty program — an industry first for ransomware
operations — and added new extortion mechanisms including the ability to pay to
have victim data deleted or to extend countdown timers. The encryptor itself
borrows significant code from the leaked BlackMatter ransomware source code.

==============================================================================
BACKGROUND: LOCKBIT RaaS
==============================================================================

LockBit first emerged in September 2019 as ABCD ransomware. The operation evolved
through LockBit 1.0 (2020), LockBit 2.0 (2021, code-named LockBit Red), and
culminated in LockBit 3.0 (2022, code-named LockBit Black). The group claims to
have the fastest ransomware encryption speed of any RaaS operation, a claim
forensically supported by researchers analyzing encryption benchmarks.

The LockBit core team provides affiliates with a builder to generate customized
payloads, a victim-facing negotiation panel, and a data leak site. Affiliates
typically receive 70-80% of ransom payments. In 2023, LockBit was responsible for
approximately 25-28% of all publicly known ransomware attacks.

==============================================================================
INFECTION CHAIN
==============================================================================

Phase 1 — Initial Access:
LockBit affiliates employ diverse initial access methods. In the incidents analyzed
for this report, the following were observed:

  (a) Exploitation of public-facing applications:
      - Fortinet FortiOS SSL-VPN vulnerabilities (CVE-2023-27997, CVE-2022-40684)
      - PaperCut NG/MF authentication bypass (CVE-2023-27350)

  (b) Purchase of access from Initial Access Brokers (IABs) via dark web forums,
      typically RDP credentials or VPN session tokens from previous info-stealer
      infections.

  (c) Phishing emails delivering malicious macro-enabled Office documents.

Phase 2 — Post-Compromise Actions:
After establishing a foothold, affiliates typically spend days to weeks performing
reconnaissance and lateral movement before deploying the ransomware. Observed tools:
  - Cobalt Strike beacons (multiple variants)
  - Mimikatz for credential harvesting
  - Advanced IP Scanner / SoftPerfect Network Scanner for discovery
  - AnyDesk / TeamViewer for persistent remote access
  - Rclone for data exfiltration to cloud storage (MEGA, Dropbox)

Phase 3 — Ransomware Deployment:
The LockBit 3.0 encryptor is deployed via GPO or PsExec across domain-joined hosts.
Before encryption, the malware:
  - Terminates security tools and backup processes
  - Deletes Volume Shadow Copies (vssadmin delete shadows /all)
  - Disables Windows Defender via registry modifications
  - Enumerates and encrypts files matching target extensions, skipping system-critical files

File encryption uses AES-256 in CTR mode; the AES key is encrypted with an
embedded RSA-2048 public key. Files are renamed with a random extension appended.
