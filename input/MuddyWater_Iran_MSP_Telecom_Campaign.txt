MuddyWater (Static Kitten): Iranian APT Targets Telecommunications and IT Managed Service Providers
Published: 2024-02-20
Source: Symantec Threat Hunter Team
TLP: WHITE

==============================================================================
EXECUTIVE SUMMARY
==============================================================================

The Symantec Threat Hunter Team has observed an active campaign attributed to
MuddyWater (also known as Static Kitten, Seedworm, TEMP.Zagros, and Mercury),
an Iranian state-sponsored threat actor assessed to operate under Iran's Ministry
of Intelligence and Security (MOIS).

The campaign targets telecommunications providers and IT Managed Service Providers
(MSPs) in the Middle East, Central Asia, and Eastern Europe. By compromising MSPs,
MuddyWater gains access to the MSP's downstream customer environments, enabling
a supply chain-style attack that affects hundreds of organizations simultaneously.

The actor employs spear phishing combined with exploitation of remote monitoring
and management (RMM) tools already deployed in victim environments, notably
connecting to victims via compromised SimpleHelp and Atera instances to establish
secondary access alongside their custom POWERLESS backdoor.

==============================================================================
BACKGROUND: MUDDYWATER
==============================================================================

MuddyWater has been active since at least 2017 and primarily targets countries in
the Middle East (Saudi Arabia, Turkey, Israel, UAE) and neighboring regions.
In 2022, CISA and partner agencies published a joint advisory attributing MuddyWater
to MOIS and documenting its use of open-source offensive security tools alongside
custom malware.

The actor commonly uses:
  - Spear phishing with ZIP archives containing LNK or Office documents
  - Open-source tools: Ligolo-ng (tunneling), Chisel (SOCKS proxy), Invoke-Obfuscation
  - POWERLESS backdoor (PowerShell-based)
  - PhonyC2 command and control framework (custom Python)
  - DROKBK malware (GitHub-based C2)
  - Heavy reliance on Living-off-the-Land (LotL) techniques to blend in

==============================================================================
TECHNICAL ANALYSIS
==============================================================================

Initial Compromise — Phishing:
Emails purport to be from industry associations or regulatory bodies:
  - Subject: "Telecom Regulatory Update — Q1 2024 Compliance Documentation"
  - Subject: "IT Infrastructure Security Assessment — Participation Required"

The ZIP archive contains an LNK file that, when double-clicked, executes a
PowerShell one-liner downloading POWERLESS from an attacker-controlled URL.

POWERLESS Backdoor (latest variant):
POWERLESS is an obfuscated PowerShell script. The latest variant observed uses:
  - String concatenation and Base64 encoding throughout
  - AMSI bypass: [Ref].Assembly.GetType('System.Management.Automation.AmsiUtils')
                  .GetField('amsiInitFailed','NonPublic,Static').SetValue($null,$true)
  - Persistence: Scheduled task named "Windows Defender Update Task"
  - C2: Uses HTTP polling to PhonyC2 server (custom Python C2 framework)
  - Supports: command execution, file upload/download, screenshot, lateral movement

PhonyC2 Framework:
PhonyC2 is MuddyWater's custom C2 framework written in Python. It mimics legitimate
web server responses, returning HTTP 200 with body content from a predefined
"decoy" HTML page when accessed without proper authentication headers. Only
properly authenticated POWERLESS agents receive tasking. All communication uses
AES-256-GCM encryption.

RMM Tool Abuse:
After establishing initial access via POWERLESS, MuddyWater operators accessed
victim SimpleHelp and Atera RMM instances using credentials harvested from the
compromised MSP server (found in plaintext configuration files). This allowed
them to push deployments to end-customer environments without further exploitation.

Tunneling / Lateral Movement:
  - Ligolo-ng used to create reverse tunnels from DMZ-segment hosts back to C2
  - Chisel used for SOCKS proxy to enable direct RDP access to internal hosts
  - PsExec for lateral movement across Windows environments
