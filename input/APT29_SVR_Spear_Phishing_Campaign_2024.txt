APT29 / Cozy Bear: SVR-Linked Spear Phishing Campaign Targeting Government Entities
Published: 2024-03-15
Source: Unit 42, Palo Alto Networks
TLP: WHITE

==============================================================================
EXECUTIVE SUMMARY
==============================================================================

Unit 42 has identified an ongoing spear phishing campaign attributed with high
confidence to APT29 (also known as Cozy Bear, The Dukes, or Nobelium), a threat
group assessed to operate on behalf of Russia's Foreign Intelligence Service (SVR).
The campaign, active since January 2024, targets foreign ministries, embassies,
and government contractors across NATO member states and partner countries.

The attackers leverage legitimate cloud services for command and control (C2),
making detection particularly challenging. The infection chain employs a novel
HTML smuggling technique to deliver a ROOTSAW-variant dropper, ultimately
deploying the WINELOADER backdoor observed in earlier campaigns.

==============================================================================
BACKGROUND: APT29
==============================================================================

APT29 is one of the most sophisticated and persistent threat actors tracked by the
security community. Active since at least 2008, the group is known for targeting
government entities, think tanks, healthcare organizations, and technology firms.
The group gained international notoriety following the 2016 Democratic National
Committee (DNC) breach and the 2020 SolarWinds supply chain attack.

APT29 is distinguished by its meticulous operational security, use of legitimate
cloud infrastructure (OneDrive, Dropbox, Notion), and custom malware families
that evolve continuously to evade detection.

==============================================================================
CAMPAIGN DETAILS
==============================================================================

Initial Access:
The campaign begins with spear phishing emails crafted to impersonate legitimate
diplomatic correspondence. Emails are sent from compromised email accounts belonging
to foreign ministries or from newly registered domains with convincing typosquatting
patterns (e.g., mfa-germany[.]org, embassy-support[.]net).

The emails carry HTML attachments containing smuggled ZIP archives. When opened in
a browser, the JavaScript within the HTML file decodes a base64-encoded payload
and writes a ZIP file to disk, bypassing email gateway filters that rely on static
attachment analysis.

The ZIP archive contains a Windows shortcut (.lnk) file masquerading as a PDF
diplomatic document. Executing the .lnk file triggers a PowerShell command that
downloads the second-stage loader from attacker-controlled infrastructure.

Second-Stage Loader (ROOTSAW Variant):
The loader, internally tracked as ROOTSAW.B, is a 32-bit DLL written in C++.
It performs environment checks to detect sandboxes (checking for minimum RAM, CPU
count, and recently accessed files) before proceeding. If the environment is deemed
safe, the loader decrypts and reflectively loads the final payload (WINELOADER)
directly into memory.

WINELOADER Backdoor:
WINELOADER communicates with its C2 server via HTTPS, blending into normal traffic
by using legitimate-looking TLS certificates and hosting the C2 panel on compromised
WordPress sites or Notion pages. The backdoor supports the following commands:
  - File upload/download
  - Shell command execution
  - Screenshot capture
  - Credential harvesting from browsers (Chrome, Firefox, Edge)
  - Lateral movement via pass-the-hash and SMB

==============================================================================
RECOMMENDATIONS
==============================================================================

1. Block all listed IoCs at the network perimeter and endpoint level.
2. Apply patches for CVE-2023-23397 and CVE-2024-21413 immediately.
3. Enable Protected View and disable automatic preview in Outlook.
4. Monitor for outbound HTTPS connections to newly registered domains (<30 days old).
5. Deploy detections for HTML smuggling techniques in email gateways.
6. Audit privileged accounts for pass-the-hash indicators in Windows event logs (Event ID 4624, Logon Type 9).
