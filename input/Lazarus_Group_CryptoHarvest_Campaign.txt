Lazarus Group: Cryptocurrency Exchange Theft Campaign (Operation AppleJeus Follow-on)
Published: 2024-02-08
Source: Kaspersky Global Research and Analysis Team (GReAT)
TLP: WHITE

==============================================================================
EXECUTIVE SUMMARY
==============================================================================

Kaspersky GReAT has been tracking a cryptocurrency theft campaign attributed to
the Lazarus Group (APT38 financial operations cluster), a North Korean state-
sponsored threat actor operating under the Reconnaissance General Bureau (RGB).
The campaign, which we designate Operation CryptoHarvest, has resulted in the
theft of approximately $147 million USD worth of cryptocurrency assets between
October 2023 and January 2024.

The threat actor employs a multi-stage infection chain that begins with fake
cryptocurrency-related job offers on LinkedIn and professional networks. Victims
are lured into downloading what appears to be a coding challenge or skills
assessment, which is actually a trojanized application bundle containing a
macOS/Windows cross-platform backdoor (POOLRAT variant) and a novel cryptocurrency
wallet stealer module we name CRYPTOSHIFT.

==============================================================================
BACKGROUND: LAZARUS GROUP
==============================================================================

Lazarus Group is one of the most prolific and financially motivated nation-state
threat actors. Unlike most APT groups focused on espionage, Lazarus conducts large-
scale financial theft to generate hard currency for the North Korean regime, which
faces severe international sanctions. The group is responsible for:

  - 2014 Sony Pictures hack
  - 2016 Bangladesh Bank SWIFT heist ($81M stolen)
  - 2017 WannaCry global ransomware attack
  - 2018-present: Serial cryptocurrency exchange thefts (total estimated >$3B)
  - 2022 Axie Infinity/Ronin Bridge hack ($625M)

The AppleJeus campaign family, first documented in 2018, involves distributing
trojanized cryptocurrency trading applications targeting macOS and Windows users.
CryptoHarvest represents a third-generation evolution of this campaign family.

==============================================================================
TECHNICAL ANALYSIS
==============================================================================

Stage 1 — LinkedIn Social Engineering:
Attackers create convincing fake recruiter profiles impersonating staff at prominent
cryptocurrency firms (Binance, Coinbase, Kraken). Targets receive InMail messages
describing senior developer positions with competitive compensation packages.
Interested targets are directed to a "technical assessment" hosted on GitHub or
a dedicated website mimicking a legitimate company's careers portal.

Stage 2 — Trojanized Application:
The "assessment" package is distributed as a signed application bundle:
  - macOS: DMG file containing a Python-based trading dashboard (PyQt5 GUI)
  - Windows: NSIS installer delivering a .NET WinForms application

In both cases, the visible application is functional — a real cryptocurrency price
tracker — to avoid immediate suspicion. The malicious components execute silently
in background threads.

==============================================================================
CRYPTOSHIFT TECHNICAL BEHAVIOR
==============================================================================

Upon execution, CRYPTOSHIFT enumerates browser extension directories for known
cryptocurrency wallet extensions using hardcoded extension IDs:

  Metamask:  nkbihfbeogaeaoehlefnkodbefgpgknn
  Coinbase:  hnfanknocfeofbddgcijnmhnfnkdnaad
  Phantom:   bfnaelmomeimhlpmgjnjophhpkkoljpa
  TronLink:  ibnejdfjmmkpcnlpebklmnkoeoihofec

For each wallet found, it copies the LevelDB database files to a staging directory,
encrypts them with an embedded AES-256 key, and exfiltrates via HTTPS POST to the
C2 server. The stealer also captures screenshots every 30 seconds and keylogged
input near cryptocurrency-related windows (detected by window title string matching).
